# Facility PBR tiles

These self-contained 512px material sets are photo-derived from the industrial-facility reference in `references/inspiration/17e96510-a0e6-11f1-bf60-039a9cb896aa.webp`.

- `painted-steel-*`: corrugated olive painted cladding; used for façade and panel families.
- `asphalt-*`: wet, worn industrial tarmac; used for roadway and loading-apron families.
- `concrete-*`: poured sidewalk/pad surface; used for concrete and sidewalk families.

Each set contains `albedo`, `roughness`, `normal`, and `metalness` maps. The generated GLB embeds them, so runtime loading does not depend on this directory.
